# w3tweaks-feedback

Public feedback, questions, and discussion for [w3tweaks.com](https://www.w3tweaks.com) tutorials.

## How to ask a question

[**Open a new issue**](../../issues/new) — pre-fill the title with the tutorial name and paste your question.

Most articles on w3tweaks.com have a "Got a question about this tutorial?" button at the bottom that opens a pre-filled issue here. That's the fastest path.

## What this repo is for

- Questions about specific tutorials ("the code in step 3 doesn't work in Firefox")
- Suggestions for improvements ("could you add a section on X?")
- Topic requests ("a tutorial on Y would be great")
- General feedback on the site

## What it's not for

- Bug reports about w3tweaks.com itself (broken pages, layout issues) — those go to a different repo
- Personal support requests outside the scope of a tutorial
- Spam, off-topic discussion, or self-promotion

## Response time

We read every issue. Replies usually within 1–3 days, sometimes faster.

## Code of conduct

Be kind. Assume good faith. We're all here to learn.
